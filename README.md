# Охотники за привидениями · ЛогоЛенд

Сюжетная браузерная игра для чтения открытых и закрытых слогов. Четыре комнаты, **ровно четыре призрака в каждой**, всего 16. На чердаке: три обычных призрака и хозяин особняка, которого нужно захватить три раза.

## Запуск

Статический сайт без зависимостей и сборки. Нужен HTTP-сервер (ES-модули и звук не работают через file://).

```sh
npm start
# http://127.0.0.1:4173
npm test
```

## GitHub Pages и Genially

Включите в Settings → Pages → Build and deployment публикацию из ветки `main`, папка `/ (root)`. После развёртывания адрес игры:

https://propodgotovkaa-creator.github.io/oxota/

Этот адрес можно вставить в Genially как внешний контент. Пример для сайта:

```html
<iframe src="https://propodgotovkaa-creator.github.io/oxota/"
  title="Охотники за привидениями — ЛогоЛенд"
  style="width:100%;aspect-ratio:16/9;border:0;display:block"
  allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Игра сама вписывает поле 16:9 в доступное окно без прокрутки. Для планшета удобнее горизонтальное положение.

## Управление

Мышь или касание направляет насадку. Удержание включает поток. Захват длится около 2,35 секунды (босс — 2,8 секунды на этап). Отпускание, уход за поле, отмена касания и потеря фокуса прерывают захват. Пауза сохраняет прохождение; проигрыша и таймера нет. Кнопка звука доступна во всех сценах. Фоновая музыка выключена; остаются звуковые эффекты. Призраки появляются по очереди с интервалом 2,6 секунды. Если видимого призрака долго не ловить, он приближается к игроку и увеличивается, затем отступает. Захват прерывает атаку; урона и проигрыша нет.

Перед каждой комнатой педагог проверяет чтение вслух и нажимает кнопку зарядки. Автоматического распознавания речи нет. При большом наборе все слоги разбиваются на страницы по 12; набор не ограничен шестнадцатью. Повторы разрешены только после исчерпания комбинаций. Ь и Ъ отображаются в алфавите, но не входят в двухбуквенные слоги. Й используется в закрытых слогах.

## Файлы

- `src/syllables.js` — генерация и распределение слогов.
- `src/main.js` — меню, чтение, переходы, финал и Pointer Events.
- `src/scenes.js`, `src/ghosts.js`, `src/vacuum.js` — сцены, поведение, захваты.
- `src/renderer.js` — анимация, деформация спрайтов, поток и гибкий шланг.
- `src/audio.js` — локальные музыкальные и звуковые ресурсы.
- `assets/` — согласованные художественные изображения, детали и WAV-звуки.
- `tools/make-audio.mjs` — исходник оригинальной синтезированной музыки и эффектов.
- `tests/game.test.js` — проверки слогов, количества призраков, захвата и босса.

Все ресурсы локальны, сторонние CDN, аналитика и сбор персональных данных отсутствуют. Графика создана встроенным Imagegen и согласована пользователем. Исходное ТЗ хранится в `SPECIFICATION.txt`; позднейшее уточнение пользователя имеет приоритет: в библиотеке и лаборатории также по четыре призрака.
